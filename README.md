# HungryAPI 🍽️

A simple restaurant management REST API built with Spring Boot.

---

## Features

- Add, update, delete, and get all dishes
- Add and fetch customers
- Place food orders
  - Calculates total price
  - Skips unavailable dishes
  - Stores order time automatically

---

## Tech Stack

- Java
- Spring Boot
- MySQL
- JPA      
- Lombok
